Python Group Project

Fixed-Length File Management System
Group Project (2-3 Students)

Project Overview

For this group project, your team will design and develop a complete Python application that manages data using fixed-length record files. The application must allow users to create, view, search, update, and delete records through a menu-driven interface.

You may work in groups of 2 or 3 students and select your own project topic.

Important Note on AI Usage

The use of AI tools such as ChatGPT, Microsoft Copilot, Claude, Gemini, GitHub Copilot, and similar code assistants is permitted for this project.

  • Explain how the program works
  • Explain the purpose of major functions
  • Explain file handling logic
  • Explain CRUD operations
  • Explain validation and exception handling
  • Answer questions about submitted code

All group members are responsible for understanding all submitted code, including AI-generated code.
